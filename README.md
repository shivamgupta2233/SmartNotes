# 📝 Smart Notes

A modern Notes Management System built using **Python Flask**.

## 🚀 Features

- ✅ Add Notes
- ✅ Edit Notes
- ✅ Delete Notes
- ✅ Search Notes
- ✅ Category Filter
- ✅ Favorite Notes
- ✅ Pin Notes
- ✅ Dashboard Analytics
- ✅ Dark Mode
- ✅ Export to PDF
- ✅ Export to CSV
- ✅ Responsive UI

## 🛠 Tech Stack

- Python
- Flask
- SQLite
- SQLAlchemy
- HTML
- CSS
- Bootstrap 5
- JavaScript

## ▶️ Run Locally

```bash
pip install -r requirements.txt
python3 app.py
```

Open:

```
http://127.0.0.1:5001
```
